# AL BLACK RABBIT HIT

منصة تواصل اجتماعي متكاملة تجمع: محادثات فورية، فيديوهات قصيرة (Reels)، فيديو، ألعاب، ومجتمع تفاعلي — بهوية بصرية موحّدة (شخصية الأرنب "Rabbit Hit").

## 📌 حالة المشروع

| الجزء | الحالة |
|---|---|
| تصميم UI/UX لكل الشاشات | ✅ مكتمل |
| نموذج أولي تفاعلي (Prototype) | ✅ مكتمل — `prototype/app.html` |
| الهوية البصرية / الأصول (Logo, Assets) | ✅ مستخرجة — `assets/` |
| الواجهة الخلفية (Backend) | ⏳ لم يبدأ |
| قواعد البيانات والحسابات الحقيقية | ⏳ لم يبدأ |
| المحادثات الفورية الحقيقية | ⏳ لم يبدأ |
| رفع/بث الفيديو والـReels | ⏳ لم يبدأ |
| تطبيقات الجوال (iOS/Android) | ⏳ لم يبدأ |
| الإطلاق الرسمي | ⏳ لم يبدأ |

> هذا المستودع نقطة انطلاق موثّقة، وليس منصة جاهزة للإنتاج بعد. راجع `docs/ROADMAP.md` لما تبقّى فعلياً قبل الإطلاق.

## 📁 هيكل المشروع

```
├── prototype/
│   └── app.html        ← النموذج التفاعلي الحالي (تصميم كل الشاشات + تنقل + دعم لغتين)
├── assets/
│   ├── rabbit-logo.png ← شعار الأرنب الدائري (مقتطع من التصميم الأصلي، بدون تعديل)
│   └── reel-scene.jpg  ← مشهد الأرنب في غرفة الـReels (من التصميم الأصلي)
├── docs/
│   ├── ROADMAP.md       ← خارطة الطريق الكاملة حتى الإطلاق الرسمي
│   └── ARCHITECTURE.md  ← التقنيات والبنية المقترحة للواجهة الخلفية والبنية التحتية
└── README.md
```

## ▶️ تشغيل النموذج الأولي

النموذج لا يحتاج أي تثبيت — افتح `prototype/app.html` مباشرة في أي متصفح (يدعم الجوال، التابلت، الحاسوب، والشاشات الكبيرة).

## 🗺️ الخطوات القادمة

راجع [docs/ROADMAP.md](docs/ROADMAP.md) للمراحل التسع المتبقية قبل الإطلاق الرسمي، و[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) للتقنيات المقترحة.
